# Nitpick MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the Nitpick MVP defined in `docs/SPEC.md`: local voice-to-text with optional BYOK cloud Modes, four tabs, quiet-utility UI, GPLv3.

**Architecture:** Layered per SPEC section 12. Pure logic (dictionary, protection, secret guard, provider normalization) is built test-first with no UI dependency. System services (keychain, audio, transcription, context, accessibility) sit behind protocols so features and tests use stubs. Features are SwiftUI views over those protocols. One pipeline orchestrator wires shortcut → record → transcribe → dictionary → mode → insert/answer → history.

**Tech Stack:** Swift 6 (strict concurrency), SwiftUI + AppKit, SwiftData, URLSession, Security.framework, ScreenCaptureKit, AVFoundation, FluidAudio (only third-party dep). Swift Testing for unit/integration, XCTest for UI tests. XcodeGen project.

**Working agreements:** TDD for all pure logic. Commit per task. `xcodebuild test -scheme Nitpick -destination 'platform=macOS,arch=arm64' -only-testing:NitpickTests` must pass before every commit.

## Phase 1: Core domain + Dictionary engine

### Task 1.1: Core value types
Files: `Nitpick/Core/Models/CoreTypes.swift`
- `NitpickAction` enum: `.dictate`, `.ask`.
- `ProviderID` enum: `.groq`, `.openRouter`, `.sambaNova`, `.cerebras` (Codable, CaseIterable, display name, base URL, dashboard URL).
- `ModelCapability` enum: `.text`, `.image`, `.unknown`.
- `CloudModelDescriptor` struct per SPEC 9.3.

### Task 1.2: Dictionary engine (TDD)
Files: `Nitpick/Services/Dictionary/DictionaryEngine.swift`, `NitpickTests/DictionaryEngineTests.swift`
- Input: transcript + `[DictionaryRule]` (phrase, replacement, enabled, caseSensitive).
- NFKC normalization for matching, locale-aware word tokenization (`enumerateSubstrings(.byWords)` over the raw string preserving ranges), token trie, left-to-right longest complete match, whole-word boundaries only, punctuation preserved, disabled rules skipped, case-insensitive by default.
- Tests: single word, multi-word longest wins (`my email address` over `my email`), no substring hit (`art` never touches `partial`), punctuation preserved, case sensitivity flag, Unicode (accented, full-width) normalization, empty/degenerate inputs.

### Task 1.3: Protected replacements (TDD)
Files: `Nitpick/Services/Dictionary/ReplacementProtector.swift`, `NitpickTests/ReplacementProtectorTests.swift`
- Detect protectable values (email, URL, handle, identifier heuristics, user-marked literal flag on rule).
- `protect(text) -> (text: String, map: [Placeholder: String])` with unique non-guessable placeholders (`⟦NP0F3A⟧` style).
- `restore(text, map) -> Result<String, ProtectionError>`; malformed/missing placeholder → `.corrupted` so pipeline can fall back to pre-enhancement transcript.
- Tests: round-trip, model-mangled placeholder rejected, multiple values, adjacent punctuation.

### Task 1.4: Clipboard secret guard (TDD)
Files: `Nitpick/Services/Context/SecretGuard.swift`, `NitpickTests/SecretGuardTests.swift`
- Reject when: exact match to stored provider key (injected set of hashes, never raw keys), private-key header (`-----BEGIN`), single-token high-entropy string (length ≥ 20, Shannon entropy threshold, no spaces), known key prefixes (`sk-`, `gsk_`, `sk-or-`, bearer). Truncate to limit with metadata.
- Output: `.allowed(text, truncated:)` / `.omitted(reason:)`.

## Phase 2: Credentials + Providers

### Task 2.1: SecretValue + Keychain (TDD via injectable SecItem wrapper)
Files: `Nitpick/Services/Keychain/SecretValue.swift`, `KeychainStore.swift`, `NitpickTests/KeychainStoreTests.swift`
- `SecretValue`: wraps `String`, no `CustomStringConvertible` leak (`description` fixed literal via debug-only redaction), `Sendable`, comparison helper for secret guard hashing.
- `KeychainStore` protocol + `SystemKeychainStore` using generic-password items, service `io.github.shino0u0.Nitpick`, account = provider id, `kSecAttrAccessibleWhenUnlockedThisDeviceOnly`, no sync. All four SecItem calls behind `SecItemClient` protocol so tests inject a fake and assert query construction + OSStatus mapping.

### Task 2.2: Provider protocol + OpenAI-compatible adapter core (TDD with fixtures)
Files: `Nitpick/Services/Providers/CloudProviderClient.swift`, `OpenAICompatibleClient.swift`, per-provider files, `NitpickTests/ProviderTests.swift`, `NitpickTests/Fixtures/*.json`
- Protocol per SPEC 9.1. All four providers are OpenAI-compatible: one generic client parameterized by `ProviderID` (base URL, extra headers), `GET /models`, `POST /chat/completions`, bearer auth, timeouts, no auth retry.
- Normalization to `CloudModelDescriptor`; capability resolver with audited exact-ID table (OpenRouter supplies modalities in response; others default `.unknown` unless in table).
- Sanitized fixtures for each provider's `/models` shape; decode + normalize tests; capability unknown fallback test.

### Task 2.3: Model cache
Files: `Nitpick/Services/Providers/ModelCache.swift`, tests
- Persist model lists (no auth data) to Application Support JSON; stale after 24h; manual refresh; keep stale on network failure; selected-model-disappeared flag.

## Phase 4: System services (protocol-first, thin real implementations)

- `AudioRecorder` (AVAudioEngine → wav file in Application Support/History audio dir; level meter stream for waveform).
- `Transcriber` protocol + `FluidAudioTranscriber` (Parakeet model download with progress/retry, offline after install).
- `TextInserter` (Accessibility insertion; fallback → pasteboard + "Copied—paste into your app" signal).
- `ContextCollector` (frontmost app via NSWorkspace captured at action start; single NSPasteboard snapshot; single ScreenCaptureKit image of remembered app window, excluded Nitpick windows, memory-only; local time).
- `PromptAssembler` (TDD): mode instructions vs delimited untrusted context blocks, protected-value instruction, image attach only when capability == .image and permission granted.
