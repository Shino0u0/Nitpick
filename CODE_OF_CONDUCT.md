# Code of Conduct

Nitpick follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, no harassment, no personal attacks, keep discussion about the work. This applies in issues, discussions, pull requests, polls, and any project space.

Enforcement contact: report conduct issues privately via GitHub's report-abuse tools or by opening a private security advisory marked "conduct" on this repository. Maintainers will review and respond within 7 days. Consequences range from a warning to a permanent ban from project spaces, at maintainer discretion.
